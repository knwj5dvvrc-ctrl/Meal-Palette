# Meal Palette v4 — 数量対応の献立最適化

2人分の献立、78種類の収録レシピと自作レシピ、食費・在庫・買い物リストを管理するPWAです。生成AIは利用せず、説明可能なルールベース推薦です。

## v4の改善
- 在庫量を「300g」「0.2kg」「2個」などで登録し、g/kg・ml/Lを換算
- レシピの必要量と比較して不足量を表示
- 一部の食材の参考単価から追加購入費を概算し、栄養指標と合わせてランキング
- 週間買い物リストは必要量を合算してから在庫を差し引く

## 制限
- 参考単価は実売価格ではありません。単価不明の材料は金額に加算せず「要確認」と表示します。
- 収録レシピの数量単位は材料ごとに異なります。登録前にレシピ詳細で確認してください。キャベツ半玉→gなどは自動換算できません。
- 自作レシピの材料は数値入力形式で、単位は既定の単位で解釈します。
- 栄養はレシピ登録値を使う簡易評価です。アレルギーは必ず確認してください。
- データは同じ公開URLのブラウザ内に保存。更新前に「食費管理」からJSONバックアップを推奨。
